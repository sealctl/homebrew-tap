# Homebrew tap for sealctl

```sh
brew install sealctl/tap/sealctl
```

[sealctl](https://github.com/sealctl/sealctl) — your hardware wallet as an everyday developer key:
encrypted volumes, restic backups, API keys and SSH signing with the Ledger OpenPGP app.

`Formula/sealctl.rb` is updated automatically by sealctl's release workflow.
