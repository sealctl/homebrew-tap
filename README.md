# Homebrew tap for sealctl

```sh
brew install sealctl/tap/sealctl
```

[sealctl](https://github.com/sealctl/sealctl): keys for developers and their AI agents. API keys,
SSH and git signing keys, encrypted volumes and backups, unlocked from your phone: once per work session or on every use. Your AI agents never see the key. Every key is derived from 24 words held by the
sealctl phone app. Get the app from [sealctl.com/docs#install](https://sealctl.com/docs#install),
then run `sealctl pair`.

`Formula/sealctl.rb` is updated automatically by sealctl's release workflow; don't edit it by hand.
